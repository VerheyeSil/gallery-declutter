# Gallery Declutter

An Android app for decluttering your photo gallery. You swipe through photos
Tinder-style to keep or delete them, sort them into albums with minimal effort,
and browse everything as a timeline.

Everything runs on your phone, so photos never leave the device.

**Status:** planning / early development. See [docs/PLAN.md](docs/PLAN.md).

## Features (planned)

- 👉 Swipe right to keep, 👈 left to delete, 👆 up to add to an album
- Smart queues: screenshots, WhatsApp junk, duplicates, blurry shots
- Batch delete with a review step (and the system trash as a safety net)
- Suggested albums by event (time + place)
- Timeline and map view

## Development

Built with [Expo](https://expo.dev) (React Native + TypeScript).

```bash
npm install
npm start        # then scan the QR code with Expo Go on your Android phone
```
